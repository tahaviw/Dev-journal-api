#Dev Journal API

A backend learning project focused on building a REST API with Node.js.

The goal is to develop practical backend engineering skills by understanding how HTTP servers, routing, request handling, and CRUD operations work.

Tech Stack

* Node.js
* Native HTTP module
* JavaScript
* Postman

Current Features

* HTTP server setup
* Basic routing
* GET endpoints
* User retrieval by ID
* Request validation
* HTTP status codes and JSON responses

Getting Started

git clone https://github.com/tahaviw/Dev-journal-api.git
cd Dev-journal-api
npm install
npm run server

Current API Routes

Method	Endpoint	Description
GET	/	Homepage
GET	/about	About page
GET	/api/users	Get all users
GET	/api/users/:id	Get a user by ID

Main Objective

Build a functional REST API while strengthening backend fundamentals, then progress toward database integration, authentication, and full CRUD operations.

This project is a practical step toward becoming a Full-Stack and AI Engineer.
